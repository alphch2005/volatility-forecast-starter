# Quant ML Project

This project is a simple quantitative analysis workflow for SPY using Python, Jupyter, and yfinance.
It downloads SPY historical data, computes returns, visualizes price trends, and calculates rolling volatility.

## What it does
- Downloads SPY historical data
- Cleans the data
- Visualizes closing prices
- Computes returns
- Calculates rolling volatility

## Setup
1. Create and activate a virtual environment
2. Install dependencies:
   `pip install -r requirements.txt`
3. Open the notebook in the notebooks folder

## Files
- notebooks/eda.ipynb: exploratory data analysis notebook
- requirements.txt: Python dependencies
